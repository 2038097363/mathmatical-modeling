问题4正式三维产物由 `论文/figures/src/build_q4_final_assets.py` 串行生成。脚本同时读取
`q4_confirmation_freeze.json` 与正式确认首分片，核对冻结候选
`(N_A,N_B)=(619,0)`、源哈希和配置指纹，并按“确认分片中 trial ID 最小的导通实例”
选择样本；因此不会按画面效果挑选构型，也不会在 `N_B=0` 时添加示意球体。默认输出包括
场景 JSON、可编辑 FCStd、2400×1800 轴测图与顶视图、3480×1950 见证聚焦 PNG、
同内容矢量 PDF 及逐文件总哈希审计。正式生成命令为：

```powershell
python 论文/figures/src/build_q4_final_assets.py `
  --freeze-json 问题/问题4/results/D_screen2000_confirm50000/q4_confirmation_freeze.json `
  --confirmation-shard 问题/问题4/results/D_screen2000_confirm50000/confirmation/pareto_max_A000619_B005483/shards/shard_000000_000099.json
```

容量测试的临时原件已清理，仅保留对象数、文件规模和渲染可行性汇总；这些汇总不得作为
论文图件或正式数值结果源。

执行时由系统 Python 创建 ASCII 临时目录，FreeCAD 命令行不接收项目中文路径；完整 GUI 进程
以 Windows 隐藏窗口方式运行，宏内再次隐藏主窗口，超时路径会终止进程树。FCStd 缺少
`GuiDocument.xml`，故渲染器仅在内存中按 `build_freecad_scene.py` 的既定角色恢复可见性和
颜色，并将域改为线框以避免透明面遮挡；不保存模型，不更改几何、`SourceIds` 或见证 ID。
重建后的模型本体还保存 `PublicationStatus=formal_result` 和 `SceneMetadataJSON`，其中含正式
场景/片段模式、工作簿与见证文件哈希、组别、结论和见证行，可脱离旁置说明核验语义。

每幅 PNG 的同名 `.audit.json` 是像素与复现权威记录。顶视投影只用于路径展开和组间比较，
轴测图用于展示真实三维几何；两类视图都不能以目测交叉替代问题1图算法的距离判据。最终正文
应至少保留一张轴测图，并在排版后复核组合图尺寸、图注和打印可读性。
