# 问题四计算模型与实现

## 权威程序

- `src/solve.py`：生成混合微构体、构建静态接触图并输出每个 trial 的二维 Pareto 路径前沿。
- `src/audit_confirmation.py`：合并 50000 次分片并独立审计 $620\times5484$ 成功次数矩阵。
- `src/finalize_positive_domain.py`：在 $N_A,N_B\ge1$ 上完成成本枚举、置信分支计算、结果冻结和注册。

## 计算链

1. A、B 使用独立随机流生成，共同前缀保证数量增加时原有粒子不变。
2. 每个 trial 构建最大设计 $(619,5483)$ 的静态图。
3. 多目标瓶颈路径算法保留右电极的非支配激活标签。
4. 用二维差分与累加把 50000 个前沿转换为成功次数矩阵。
5. 正整数后处理对每个 A 行二分查找首个经验可行 B 数，再按整数成本排序。
6. 在 $N_B=1$ 分支计算 619 项校正的单侧精确下界，并读取问题三 616 根记录作交叉验证。

## 复杂度与复现

最昂贵部分是 50000 个最大静态图的几何接触搜索；正整数域枚举只读取约 13 MiB 的压缩计数矩阵，
数秒内即可重现。正式结果命令为

```powershell
python 问题/问题4/src/finalize_positive_domain.py --register-results
```
