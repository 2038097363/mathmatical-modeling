## 已执行的小规模验证

执行命令：

```powershell
python -m unittest discover -s tests -p "test_mixed_microstructure_sim.py" -v
python -m unittest discover -s tests -p "test_q4_solver.py" -v
```

D 混合几何/分片/二维前沿测试和 Q4 冻结/决策测试均已通过。测试只使用解析构型、
小网格及 1--4 个 trial，不构成正式概率结果。正式 2000/50000 样本完成后，还需检查
分片完整性、窄相未判定计数、Monte Carlo 计数、CP 限和结果哈希。

## 局限与失败区域

1. B 球片是严格球盒交集；A 仍按中心线交点切成较短平底圆柱，未重建半径侧缘越界和斜切布尔面。
2. 精确球内外符号使用 `math.fma`，运行环境低于 Python 3.13 时主动停止，而不是退化为未经认证的普通平方。
3. GJK 距离界若在收紧后仍跨越 1.8 nm 阈值会停止该 trial，不能把未判定强行归为接触或不接触。
4. 有限样本只支持冻结协议下的统计陈述；未排除的更便宜极大点会阻止全局最低成本措辞。
5. 当前尚未运行边界模式 B/A 的敏感性，也未运行正式大样本，因此不报告数值最优方案。

## 拓展决策

边界模式 B/A 可在 D 主结果冻结后作为敏感性对照，但必须各自使用明确几何合同、独立
stream 和单独结果标签，不能混入 D 的最低成本证明。A 的完整三维布尔切分只有在中心线
近似被证明会实质改变候选排序时才值得升级；在此之前保留限制说明比伪造精确圆柱切面更可靠。
