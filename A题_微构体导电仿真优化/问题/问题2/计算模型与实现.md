# 问题2计算模型与实现

## 权威代码与样本合同

- 共享仿真内核：`公共代码/microstructure_sim.py`。
- 权威入口：`问题/问题2/src/solve.py`。
- 每次试验先一次性生成 `max_count` 个原始 A，再按原粒子顺序增量加入图；返回首次导通的原粒子编号（从 1 开始）。截至 `max_count` 仍不导通时记为 `max_count+1`，该值只表示右删失。
- 题给 `354、424、495、707` 四个数量从同一组首次导通样本计算，因而样本级概率随数量单调，且没有四次独立模拟造成的比较噪声。

## 边界模式

|模式|中心线处理|同源片段内部边|用途|
|---|---|---|---|
|D|在 X/Y/Z 的 `±5000 nm` 交点切段，各开区间按中点所在周期胞映入基础立方体|不添加|Q2/Q3 主模型|
|B|先把中心线裁到 X slab，再在 Y/Z 边界切段并周期映射|添加|开放 X 电极敏感性|
|A|与 D 相同的三轴显式切段和映射|添加|仅作敏感性|

所有模式均只在显式映射后的基础立方体内计算普通欧氏距离，禁止全局 minimum-image 邻接。每个映射区间表示为有限平底圆柱，切口是垂直圆柱轴的平端面。

D 模式和 B 模式都以中心线与边界的交点定义短平底圆柱，不是完整三维圆柱与盒子的布尔
交；半径侧缘越界及斜切边界层未被精确表示。正式结果必须把这一点作为几何离散局限披露。

## 随机生成与几何判定

- 中心在 `[-5000,5000]^3` 内 IID 均匀。
- 方向令 `cos(theta)` 在 `[-1,1]` 均匀、方位角在 `[0,2pi)` 均匀。
- 中心和方向分别使用 `SeedSequence([master_seed, stream_id, trial_id, quantity_code])`；所有标识均为稳定整数，不使用 Python 字符串哈希。
- AABB 空间哈希只产生候选对；胶囊距离只作平底圆柱距离的安全下界宽相。
- 所有未被宽相排除的候选调用 `geometry_kernel.py::distance_bounds`，用正式 GJK 距离上下界裁决 `1.8 nm` 接触阈值。收紧容差后区间仍跨阈值时直接报错，不按中点猜测。
- 圆柱到 `x=±5000` 电极面的距离使用凸体投影闭式式；图连通用并查集，可选 BFS 恢复路径见证。

## 固定试验数、分片与续跑

`SimulationConfig` 把边界模式、几何常数、最大粒子数、固定试验数、种子、流编号和数值容差写入规范 JSON，并计算 SHA-256 配置指纹。批次文件按 trial ID 的连续区间命名；续跑时先核对指纹与精确 ID 范围。合并器拒绝重复 ID、不兼容配置和缺失试验，并按 trial ID 确定排序。CPU 多进程只改变调度，不改变任何随机流。

正式样本流写入 `问题/问题2/results/D_primary_n20000/threshold_samples.json`，Q2 汇总写入同目录的 `q2_summary.json`。

## 概率与区间

对数量 `n`，以首次导通样本 `T_r` 定义

\[
\hat p(n)=R^{-1}\sum_{r=1}^{R}\mathbf 1(T_r\le n).
\]

同一成功数同时输出 95% Wilson 区间和由 `scipy.stats.beta` 计算的 Clopper-Pearson 精确区间。粒子数对应的离散名义体积分数由未取整的几何体积重新计算。

## 复现命令

主结果使用固定试验数、批大小、随机流和输出目录：

```powershell
python "问题/问题2/src/solve.py" --boundary-mode D --max-count 720 --trials 20000 --seed 20260801 --stream-id 2 --workers 8 --batch-size 20 --counts 354 424 495 707 --output-dir "问题/问题2/results/D_primary_n20000" --resume --register-results
```

B、A 模式仅用于边界敏感性检验，不进入 D 主结果。
