# 系统边界与机理链

## 研究对象与边界

计算域为

\[
\Omega=[-L/2,L/2]^3,\qquad L=10000\ \mathrm{nm},
\]

左右带电面为 $E_L:\,x=-L/2$ 和 $E_R:\,x=L/2$。介质 A 是轴长
$\ell_A=5000\ \mathrm{nm}$、半径 $r_A=30\ \mathrm{nm}$ 的有限平底直圆柱；介质 B 是
半径 $r_B=200\ \mathrm{nm}$ 的球。绝缘溶剂不作为图节点，四个非电极面不带电。

系统输入包括粒子类型、数量、中心和方向；中间状态是经过边界规则处理后的有限实体及其接触图；
输出是左右电极是否连通、该事件在声明随机模型下的概率，以及满足概率约束的整数填充方案。
题面没有给出电导率、电压、电流、接触电阻或隧穿衰减函数，因此不建立电流场 PDE 或加权电阻网络。

## 状态、设计、控制、观测与扰动

- 状态变量：每个有限实体的位置、方向、类型、边界表示片段、接触邻接关系和连通分量。
- 随机变量：粒子中心、A 的单位方向，以及由它们诱导的导通指标 $Y\in\{0,1\}$。
- 设计变量：问题 3 的整数 $N_A$；问题 4 的非负整数对 $(N_A,N_B)$。
- 观测量：问题 1 的附件坐标；问题 2-4 的 Monte Carlo 导通次数 $k$ 与样本数 $n$。
- 固定参数：$L,\ell_A,r_A,r_B,\delta=1.8\ \mathrm{nm}$ 及两类单位体积成本。
- 模型不确定性：题面未给出的随机分布，以及轴线裁切表示对完整圆柱边界交集的近似。跨边界
  电学语义已由组委会答复为“截断片段独立”。

## 机理或逻辑链

```text
粒子数与随机种子
        -> 独立均匀中心 + A球面各向同性方向
        -> 生成平底圆柱/球并执行声明的边界规则
        -> 胶囊/AABB/空间网格安全宽相
        -> GJK或闭式公式计算有限实体最短距离
        -> 距离不超过1.8 nm时建立无向边
        -> 并查集合并粒子与左右电极
        -> Y=1{LEFT与RIGHT同一连通分量}
        -> 固定样本概率区间 / 整数阈值 / 成本前沿
```

“距离阈值 -> 接触边 -> 连通分量 -> 导通”来自题面；凸集距离使用 Gilbert-Johnson-Keerthi
方法。组委会答复决定 D 为本题主边界；Newman-Ziff 与 Tarlton 等资料只用于解释 B/A
敏感性中的开放 spanning 与周期 wrapping 差异，不覆盖官方澄清，也不提供本题概率数值。

## 初始与边界条件

### 概率空间

每种介质的中心独立服从 $U(\Omega)$；A 的方向采用

\[
\varphi\sim U[0,2\pi),\quad \mu=\cos\theta\sim U[-1,1],\quad
u=(\sqrt{1-\mu^2}\cos\varphi,\sqrt{1-\mu^2}\sin\varphi,\mu).
\]

题面明确允许相交、贯穿和重叠，故不做硬核排斥。体积分数按名义粒子体积求和，不扣除重叠区。

### 主边界 D

对 X/Y/Z 任一方向，只在原粒子实际越界时，沿题面边界交点切开并把越界段平移一个盒长。
所有映回基础立方体的截断片段均作为独立图节点；即使来自同一原粒子，也不添加内部导通边。
两个均未实际越界、但分别靠近相对面的独立粒子不使用全局 minimum-image 连接。左右电极仍
是两个不同虚拟节点，单根跨 X 粒子形成的两片不能仅凭同源关系同时短接两电极。

正式快速核按 A 的轴线与盒面交点切段，并把每段表示为较短平底圆柱。这与附件的轴端点表示
一致，但不等同于完整三维圆柱的侧缘/斜切面布尔回绕；半径 $30\ \mathrm{nm}$ 的边界层误差
作为明确局限披露，不把中心线裁切称为解析精确。

### 敏感性边界

- B：X 方向开放裁切，Y/Z 使用周期像并保持同源片段连接；它对应常见的实体电极样品边界，
  但不再作为本题主答案。
- A：XYZ 全周期并保持同源粒子内部连接，用作强连接上界；它对应 wrapping 而非双实体电极
  spanning，不能作为主答案。

## 忽略效应和适用范围

- 忽略重力、运动、碰撞排斥和形变，符合题面理想化条件。
- 忽略导电率差异、接触电阻和网络总电阻；结论只针对二值导通。
- 不把无限体系临界阈值、胶囊体阈值或硬杆阈值移植到本题有限盒。
- 所有概率结论条件于上述中心/方向分布、边界语义和名义体积分数口径。
- 官方答复确认附件无误、截断片段独立；问题 1 不按 `Y/Z=+-500` 反推 1000 nm 薄域，也不
  重联同源片段。B/A 只用于说明若改用其他边界定义，概率会如何变化。
