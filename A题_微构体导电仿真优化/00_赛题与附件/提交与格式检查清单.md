# 提交与格式检查清单

## 时间与渠道

- [ ] 竞赛时间：2026-08-07 18:00 至 2026-08-10 20:00（北京时间）。
- [ ] 截止前由队长登录赛氪报名主页提交；需要重传时以截止前最后一次系统上传为准。
- [ ] 备用邮箱仅用于报名系统上传错误；赛氪已成功提交的队伍不得重复邮件提交。
- [ ] 关注官网评论区置顶和官方 QQ 群的赛题澄清，尤其是边界截断后的电连接语义。

## 论文文件

- [ ] 采用 PDF 作为正式提交格式，单文件、不压缩、大小不超过 20 MB。
- [ ] 文件名为 `A+参赛编号.pdf`，例如 `ACM2600001.pdf`。
- [ ] 首页只填写参赛组别和参赛编号，不出现姓名、学校等身份信息。
- [ ] 首页包含论文标题、中文摘要和关键词；摘要完整且不超过第一页。
- [ ] 首页即第 1 页；每页页脚中部使用阿拉伯数字连续编号。
- [ ] 正文从第 2 页开始，不设目录；按模板与条文冲突的严格口径，正文不超过 20 页。
- [ ] 参考文献和附录置于正文之后，页数不限。
- [ ] 正文和附录均无页眉，不含任何可识别参赛者或学校的信息。
- [ ] 正文及摘要基线为宋体、小四号（12 pt）、单倍行距；A4，四边约 2.5 cm。
- [ ] 正文引用按出现次序用 `[1]`、`[2]` 标注；书籍引用注明页码。
- [ ] 附录列出实际使用的软件名称、命令和全部主程序；题给原始数据无需重复附入。
- [ ] 删除模板说明文字、红色占位内容和模板末尾空白页。
- [ ] 清除模板遗留元数据；最终 PDF 的 Author 等字段不含模板作者、队员或学校信息。

## AI 合规

- [ ] 在参考文献之前设置“AI 工具使用声明”，说明实际用途并指向附录。
- [ ] 参考文献列出 AI 工具名称、版本/型号、开发机构和使用日期。
- [ ] 附录包含工具与版本、使用环节、关键交互记录、采纳内容及人工修改情况。
- [ ] AI 辅助代码文件头包含章程要求的工具说明注释。
- [ ] AI 辅助图表在论文或图注中按章程作适当标识。
- [ ] 核心模型、推导、参数选择和结论均由参赛队理解、复核并用自己的语言表述。
- [ ] 提交前检查：期刊库查重率不超过 30%，同题自建库不超过 40%，AIGC 检测率低于 40%。

## 支撑材料与承诺书

- [ ] 支撑材料包含所有论文源程序、非题给数据、必要中间结果和难以公开获取的资料。
- [ ] 支撑材料不超过 20 MB，使用 ZIP 或 RAR，文件名如 `ACM2600001附件.rar`。
- [ ] 支撑材料内无姓名、学校、账户路径、文档作者属性或其他身份信息。
- [ ] 承诺书单独填写题号、队号、三名队员、学校和签名，核对无误后单独上传。
- [ ] 承诺书建议命名为 `CMxxxxxxx承诺书.pdf`，一页、大小不超过 50 MB。
- [ ] 论文 PDF、承诺书和支撑材料三项在系统中分别检查上传状态。
- [ ] 提交后重新下载或预览三项文件，并保存成功提交截图。
