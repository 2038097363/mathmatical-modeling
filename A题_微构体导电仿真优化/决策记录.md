## 2026-08-07 官方格式覆盖通用论文默认值

- 问题：工作流通用模板默认“摘要页不编号、正文起第 1 页”，但本届官方规范要求首页即第 1 页。
- 备选方案：沿用通用模板；严格执行本届规则。
- 采用方案：严格执行本届规则，首页页脚居中标注 1，后续连续编号。
- 证据与理由：官方《论文格式规范与提交说明》第 3 条优先级最高；Word 模板本身没有页码字段，不能据此省略页码。
- 影响位置：`论文/main.tex`、最终 PDF 渲染检查、`00_赛题与附件/提交与格式检查清单.md`。
- 需要重新运行的检查：最终 PDF 全页页码、首页摘要溢出、空白页和匿名信息检查。

## 2026-08-07 X 方向边界截断后的内部电连接暂不定案

- 问题：同一介质跨 X 边界后，留在一侧和移入相对侧的两部分是否仍通过“同一导体”保持电连接。
- 备选方案：A. 同一介质始终是一个图节点并保持内部连接；B. 截断后的几何片段不通过边界保持内部连接；C. X 方向不采用周期回绕，仅 Y/Z 采用。
- 采用方案：G2 前不定案；实现为显式可切换策略，至少比较 A 与经官方或独立论证支持的替代方案。
- 证据与理由：题面第 3 页明确用 X 方向示例，但方案 A 会使单根跨界介质直接接触两带电面，可能令问题 2-4 退化；这不是可忽略的数值误差。
- 影响位置：全部几何核、随机生成、问题 1-4 结果、论文假设与局限。
- 需要重新运行的检查：跨界单粒子、双轴越界、多粒子见证路径、两种语义的概率与最优成本敏感性。

## 2026-08-07 概率空间与体积分数采用待验证基线

- 问题：题面没有显式给出随机位置、方向分布和允许重叠时的体积分数口径。
- 备选方案：中心独立均匀且方向球面均匀；角度直接均匀；限制粒子完全内含；名义体积和或几何并集体积。
- 采用方案：将“中心独立均匀、方向球面各向同性、A/B 独立、体积分数按名义体积求和”作为最小可复现候选，等待题面逻辑、附件和官方答疑核验。
- 证据与理由：方向球面均匀要求 `cos(theta)` 均匀；允许重叠时若采用几何并集体积，题目给定体积分数不能预先唯一换算为粒子数。
- 影响位置：问题 2-4 推导、随机数生成、粒子数换算、概率和成本结果。
- 需要重新运行的检查：方向分布矩、固定种子复现、体积分数换算、概率单调性和边界假设敏感性。

## 2026-08-07 问题1采用双口径并禁止全局 minimum-image

- 问题：附件大多数行短于 5000 nm，且组1/2出现题面未说明的 `Y/Z=±500` 周期接口；若同一粒子跨 X 后保持内部连接，可直接桥接两电极。
- 备选方案：每行独立；按题设 10000 nm 立方体重联；组1/2按候选薄域重联；对所有独立粒子做全局 minimum-image。
- 采用方案：正式主结果并列“每行/片段独立且内部断开”和“题设立方体唯一接头重联且同粒子内部连接”；薄域仅作敏感性；明确禁止对任意独立粒子增加全局 minimum-image 边。
- 证据与理由：所有已选接头一对一、反向共线且映射残差为零，但部分链长度不闭合，无法唯一证明生成域。双口径下组1由不导通变为导通，说明该语义不是可忽略细节。
- 影响位置：`02_数据与参数/processed/`、`公共代码/geometry_kernel.py`、`问题/问题1/`、`结果注册表.json`；问题2-4须沿用显式边界策略配置。
- 需要重新运行的检查：`python -m unittest discover -s tests -v`；`python 问题/问题1/src/solve.py`；原附件 SHA-256；全部见证路径逐边审计；若获得官方答疑则重跑所有分问。

## 2026-08-07 问题2-4以开放X电极、横向周期为主边界

- 问题：题面既把 `x=+-5000` 定义为两个不同实体电极，又以 X 越界片段搬移作示例；若再把 X 方向全局周期化并保持同源粒子内部连接，单根跨界 A 可直接短接两电极。
- 备选方案：A. XYZ 全周期且同源片段内部连接；B. X 为开放电极、Y/Z 周期；D. 三轴只搬移实际越界部分且搬移片段作为独立节点。
- 采用方案：问题2-4以 B 为主模型；D 作为最贴题面平移字面的敏感性；A 作为 periodic wrapping 强连接上界/压力测试。三者共享随机流、粒子尺寸和精确几何核，不用结果偏好改变输入。
- 证据与理由：Newman-Ziff 明确区分开放 spanning 与周期 wrapping；Tarlton 等在导电样品中沿场方向使用实体电极、只在垂直方向使用周期边界。D 没有文献支持“同一导体的表示片段在搬移后电学断开”；A 会把两个电极方向周期识别并使四个 Q2 诊断点退化为近 1。官方赛题发布页截至 2026-08-07 没有公开澄清该语义。
- 影响位置：问题2-4的随机生成、接触图、概率、阈值和成本结果；论文假设与局限必须并列报告 B/D，A 只作强上界。
- 需要重新运行的检查：跨 X 单粒子、Y/Z 周期平移、未越界相对面粒子不得被误连、B/D/A 共同随机流概率对照；若获得官方答疑，重跑问题2-4并更新全部结果和图表。

## 2026-08-07 冻结问题2-4的概率空间

- 问题：题面允许随机位置和方向且允许贯穿/重叠，但没有给出位置密度、方向角分布和重叠时体积分数口径。
- 备选方案：中心独立均匀与球面各向同性；极角直接均匀；硬核排斥；完全内含拒绝采样；名义体积和或并集体积。
- 采用方案：各粒子中心独立均匀；A 的 `phi~U[0,2pi)`、`cos(theta)~U[-1,1]`；A/B 类型间及粒子间独立；按题面允许相交重叠；体积分数按单粒子名义体积求和。B 主边界在 X 方向截于实体样品，在 Y/Z 方向周期处理。
- 证据与理由：球面面积元要求 `cos(theta)` 均匀；题面明确允许随机生成导致贯穿和重叠，排除硬核生成；问题2先给体积分数再四舍五入粒子数，只有名义体积和能在生成构型前唯一换算数量。
- 影响位置：问题2-4推导、随机数生成、体积分数换算、固定种子和敏感性设计。
- 需要重新运行的检查：`cos(theta)` 均匀性、方向二阶矩约 `1/3`、中心坐标均匀性、前缀单调性、固定种子分片合并一致性及替代边界敏感性。

## 2026-08-08 Q4 确认候选采用探索单侧精确下限门禁

- 问题：完整整数域中“经验概率首次达到 0.90”的点在 2000 次探索样本中可能只有
  `1800/2000`，其单侧 95% Clopper--Pearson 下限仅为 `0.8882769`。直接冻结该点，
  很可能在独立 50000 次确认中无法证明候选本身可行，导致本问没有可报告设计。
- 备选方案：按探索点估计首次达到 0.90 选候选；按探索单侧 Wilson 下限选候选；按探索
  单侧 Clopper--Pearson 精确下限选候选。
- 采用方案：正式冻结前，在完整整数域中选择探索单侧 95% Clopper--Pearson 下限不低于
  0.90 且整数成本最小的设计。`n=2000` 时等价于成功次数至少 1823，点估计至少 0.9115。
  探索区间只用于选择候选，最终可行性和更便宜域排除仍全部使用独立 `stream_id=5` 的固定
  50000 次样本及预先冻结的 Bonferroni 单侧精确界。
- 证据与理由：该规则在读取正式 screen 结果前已写入求解器和测试；它降低候选确认失败风险，
  但不把探索数据当最终概率证据，也不保证全部更便宜设计都能被排除。若确认后仍有严格更便宜
  极大点未排除，结论必须降级为“最低统计可行成本”。
- 复现与版本：已完成的 screen 进程使用启动时 `solve.py` 哈希
  `A1176C68743D82C31DBA29C1647979D16BC9339EB820454950AECA46BAB125DC`；其分片只含随机
  前沿样本，与候选规则无关。冻结阶段使用新增的 `--screening-candidate-rule cp_lower` 对同一
  前沿样本只读复算完整域候选，并在冻结文件中记录新规则及源证据哈希。
- 需要重新运行的检查：`tests/test_q4_solver.py`；默认点估计候选与 CP 门禁候选的成本、成功数、
  单侧界对照；完整域计数矩阵二维单调性；冻结文件不可变性；确认流与探索流分离。

## 2026-08-08 Q3 与 Q4 的成本结论采用分层口径

- 问题：Q4 按预先冻结的探索门禁选出 `(N_A,N_B)=(619,0)` 作为独立确认候选，但 Q3 已用
  50000 次独立样本证明 `(616,0)` 的点态单侧 95% Clopper-Pearson 下限为 `0.900821`，且
  成本 `9.1439195775` 元低于 619 根方案的 `9.1884516534` 元。若把 619 根直接写成“最低
  成本”，会与已冻结的跨问题证据矛盾。
- 采用方案：619 根只称为“Q4 预冻结保守确认候选”，不称为最低成本或全局最优。Q4 完成后
  同时报告三类结果：50000 次确认完整域中的描述性经验最低成本点；预冻结候选的独立点态
  置信结论；严格更便宜极大点的同时排除状态。Q3 的 `(616,0)` 继续作为已经统计证明可行且
  更便宜的全 A 参照方案。
- 结论边界：只有当冻结协议下某方案可行且全部严格更便宜设计均被同时排除时，才允许使用
  “最低成本”表述；否则明确写为“经验最低”“保守可行方案”或“当前证据尚不能证明全局
  最低”，并给出相应成本区间与置信口径。
- 影响位置：`问题/问题4/results/`、`结果注册表.json`、Q4 成本前沿图、摘要、问题四正文、
  模型评价与结论。任何自动回填程序均不得把冻结候选标签直接转换为“最优设计”。
- 需要重新运行的检查：Q3/Q4 数值交叉扫描；全文“最低/最优”限定词扫描；摘要、表格、图注
  与结果注册表一致性；完整域单调性及更便宜极大点同时置信界审计。
